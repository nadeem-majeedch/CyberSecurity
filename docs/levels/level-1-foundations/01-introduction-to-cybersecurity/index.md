# CYB-101 · Introduction to Cybersecurity

**Level 1** · 60 minutes · **Prerequisites:** none · **Next:** [CYB-102 · CIA Triad, Principles and Risk](../02-cia-triad-principles-risk/index.md)

## Why this module exists

Most people arrive at security through headlines — a breach, a ransomware story, a leaked database.
Those stories describe *events*, not the work. This module shows you the work: what practitioners
actually do all day, why the field is organised the way it is, and what "good" looks like at the end of
your first year.

It also sets the boundary that governs everything else in this course: you will learn offensive
techniques, and you will use them **only** on systems you own or are explicitly authorized to test.

## Module outcomes

By the end of this module you can:

- Describe what cybersecurity protects and name the four broad activities practitioners perform.
- Distinguish defensive, offensive, engineering, and governance roles, and explain how they depend on
  each other.
- Explain why "the attacker only needs one mistake" shapes defensive strategy.
- State the authorization rule this course requires, and name where the full policy lives.
- Set up a notes and evidence structure you will use for the rest of the level.
