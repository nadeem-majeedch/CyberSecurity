# Start Here

New to this course? This page tells you what to read first, in what order, and why. It takes about
twenty minutes to orient yourself — which will save you hours later.

---

## The five-minute version

1. **You are learning two things at once:** how systems fail, and how to defend them. Both are
   required. Attack knowledge without defence knowledge is a liability.
2. **Everything practical happens in a lab you own.** Virtual machines, localhost services,
   deliberately vulnerable applications. Never anything else.
3. **You will write more than you expect.** Notes, captures, findings, reports. That is the job.
4. **Progress is gated.** Each level ends with an assessment; skipping ahead means hitting tools and
   concepts you have no foundation for.
5. **Confusion is normal and useful.** When you are stuck, that is the moment learning happens — but
   only if you write down what is unclear instead of clicking past it.

## What "beginning" looks like

Before you open the first lesson, you can already do three useful things:

- **Install the software** listed in [Prerequisites](prerequisites.md) and take a snapshot of a clean
  Ubuntu VM. This is CYB-108's groundwork and it is where most learners lose a weekend later.
- **Read the [roadmap](../curriculum/roadmap.md)** end to end. Knowing the shape of the program keeps
  you from over-investing in a topic that gets revisited properly at a higher level.
- **Start an evidence folder**, one directory per level, with dated notes. This habit is assessed from
  Level 1 onward, and it costs nothing to start early.

## Common first-week mistakes

- **Installing Kali immediately.** Level 1 teaches Linux fundamentals on Ubuntu Server, where you can
  see what you are doing. Tool-focused distributions hide the mechanics you need later.
- **Bridging the lab VM to the home network.** Bridged mode exposes vulnerable services to your
  household network. Host-only or NAT, always.
- **Reading without practising.** You will recognise commands you cannot use. That gap appears
  painfully in Level 2.
- **Collecting bookmarks instead of notes.** A curated reading list you never open is not progress.
